EXAMPLE: HOW INSIGHT PROPAGATION WORKS
================================================================================

Scenario: Part 3 discovers "18.5% of defects are escaped (FN%)"

PART 4 (Correlation Grouping):
  - Loads Part 3's FN rate
  - Prints: "Using Part 3's escaped defect insight"
  - Analyzes: "Which feature groups appear in escaped defects?"
  - Result: Feature groups prioritized for distinguishing escapes

PART 5 (Feature Engineering):
  - Loads Part 3: "Escaped defects: 18.5%"
  - Loads Part 4: Feature groups (from Part 4, not recreating)
  - Prioritizes: Instability features (escaped defects unstable?)
  - Prioritizes: Anomaly features (escaped defects anomalies?)
  - Result: 90-110 features engineered with escape context

PART 7 (Calibration + Threshold):
  - Loads Part 3: "Baseline FN%: 18.5%"
  - Prints: "Baseline escaped defects: 18.5%"
  - Prints: "Threshold must achieve <5% escape rate"
  - Prioritizes: 95% RECALL threshold (not 0.5 default)
  - Result: Optimal threshold = 0.28 (high recall, low FN)

WITHOUT INSIGHT PROPAGATION:
  Part 7 might have chosen: Threshold = 0.50 (F1 optimal)
  This might result in: FN% = 15% (still high!)

WITH INSIGHT PROPAGATION:
  Part 7 chooses: Threshold = 0.28 (recall optimal)
  This results in: FN% = 4% (goal achieved!)

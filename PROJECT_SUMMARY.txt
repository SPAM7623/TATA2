CORE WORKFLOW PHILOSOPHY
================================================================================

INCORRECT THINKING:
  "Which variable predicts Y?"

CORRECT THINKING:
  "Which hidden thermo-mechanical process states and parameter interactions
   create unstable operating conditions leading to Alpha defect formation?"

KEY PRINCIPLE:
  Treat each row as a complete process-state fingerprint, not as isolated
  independent variables. The X1-X49 features are anonymized process parameters.
  Their true meanings are inferred statistically through:
  - Correlation grouping (latent process-behavior clusters)
  - Instability analysis (which parameters destabilize during defects)
  - Interaction analysis (which parameter combinations matter)
